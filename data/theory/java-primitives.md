## Главное в шести правилах
- **Арифметика — минимум в `int`.** `byte`, `short`, `char` перед операцией расширяются до `int`; если есть `long`/`float`/`double` — до самого широкого операнда. Тип результата решают операнды, а не переменная слева.
- **Переполнение молчит.** `int` и `long` заворачиваются по модулю без исключения, и происходит это **до** присваивания: `long x = 30 * 24 * 60 * 60 * 1000` переполнится в `int`.
- **Составное присваивание и `++` прячут сужающий каст.** `b += 300` — это `b = (byte) (b + 300)`: компилируется и молча режет биты.
- **Целое деление округляет к нулю, знак `%` — как у делимого.** Для индексов и шардов — `Math.floorMod`.
- **`double` двоичный.** `0.1` в нём не представимо: точное сравнение бессмысленно, деньги — в `BigDecimal` или `long` в копейках.
- **`==` для `double` — по IEEE 754, `Double.equals`/`compare` — по представлению (`doubleToLongBits`).** Отсюда разное поведение с `NaN` и `-0.0`.

## Типы
- Целые знаковые, в дополнительном коде: `byte` 8, `short` 16, `int` 32, `long` 64 бита. Размеры фиксированы JLS и не зависят от платформы.
- `char` — 16 бит, **беззнаковый**, 0..65535: единица UTF-16, а не символ. Эмодзи — два `char`.
- `float` 32 и `double` 64 бита, IEEE 754: ≈ 7 и ≈ 15–16 значащих цифр.

## Операторы и приведение
- `short + short` — уже `int`; `b = b + 1` для `byte` не компилируется.
- Константное выражение, которое влезает в тип, присваивается без каста: `char c = 'a' + 1`, `byte b = k`, если `k` — `final int` со значением 10.
- `char` — число: `'a' + 'b'` = `195`, `'A' + 1` = `66`; символ — только `(char) ('A' + 1)`.
- `+` вычисляется слева направо: `'a' + 'b' + "c"` → `195c`, `"c" + 'a' + 'b'` → `cab`.
- Сдвиг берёт расстояние по модулю ширины: `1 << 32` для `int` = `1`. `>>` тянет знак, `>>>` дополняет нулями.
- Каст `double` → `int` отбрасывает дробь к нулю (`(int) -3.9` = `-3`), `NaN` → `0`, слишком большое → `Integer.MAX_VALUE`.
- `Math.round(-2.5)` = `-2`, `Math.round(2.5)` = `3`: округление половины вверх, к +∞.
- `switch` со старыми метками `case X:` проваливается до `break`; стрелочная форма `case X ->` — нет.

## Переполнение
- `Integer.MAX_VALUE + 1` = `Integer.MIN_VALUE`, без ошибки.
- `Math.abs(Integer.MIN_VALUE)` = `Integer.MIN_VALUE` — отрицательный. `Math.abs(hash) % n` раз на 4 млрд даёт отрицательный индекс.
- Защита: литерал `30L * …`, `Math.addExact`/`multiplyExact`/`toIntExact` (бросают `ArithmeticException`), `Math.absExact` (Java 15).

## Деление и остаток
- `-7 / 2` = `-3`, `-7 % 2` = `-1`, `Math.floorMod(-7, 2)` = `1`, `Math.floorDiv(-7, 2)` = `-4`.
- `x % 2 == 1` не ловит отрицательные нечётные — проверять `x % 2 != 0`.
- Шард: `Math.floorMod(hash, n)` или `(hash & 0x7fffffff) % n`.
- Целое `1 / 0` — `ArithmeticException`; `1.0 / 0` — `Infinity`, `0.0 / 0` — `NaN`, без исключения.

## double и BigDecimal
- `0.1 + 0.2` = `0.30000000000000004`. Сравнивать с допуском: `Math.abs(a - b) < eps`.
- `new BigDecimal(0.1)` = `0.1000000000000000055511…` — точное значение `double`. Создавать из строки или `BigDecimal.valueOf(double)`.
- `BigDecimal.equals` учитывает масштаб: `1.0` ≠ `1.00`. По значению — `compareTo`.
- `divide` без масштаба бросает `ArithmeticException` на бесконечной дроби (`100 / 3`). Нужно `divide(x, 2, RoundingMode.HALF_EVEN)` или `MathContext`. То же `setScale(2)` без режима.
- `HALF_EVEN` (банковское): `2.345` → `2.34`; `HALF_UP`: → `2.35`. Режим выбирает бизнес.
- Деньги в `long` минорных единиц: быстро, но число знаков зависит от валюты (`Currency.getDefaultFractionDigits`). В БД — `NUMERIC(p, s)`, рядом валюта.

## NaN и -0.0
- `==`: `NaN != NaN` (любое сравнение с `NaN` — `false`, проверка — `Double.isNaN`), `0.0 == -0.0`.
- `Double.equals`/`compare` — наоборот: `NaN` равен `NaN`, `-0.0 < 0.0`. Поэтому `HashSet<Double>` находит `NaN`, а сортировка ставит `-0.0` перед `0.0`.
- В своих `equals` для `double`-полей — `Double.compare(a, b) == 0`. `record` так и делает: `NaN`-компоненты равны.

## Сравнение разных типов
- При `int == float` оба операнда приводятся к `float`; у него 24 бита мантиссы. `16_777_217` округляется до `16_777_216` с обеих сторон — `==` даёт `true` для разных чисел.
- То же для `long` и `double` за пределами 2⁵³.
- `c == 65` для `char c = 'A'` — `true`: `char` расширяется до `int`.
