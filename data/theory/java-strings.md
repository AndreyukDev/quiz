## Главное в четырёх правилах
- **`==` у строк сравнивает ссылки.** Совпадает только у литералов и констант времени компиляции — они из пула. Строки из БД, JSON, `substring`, конкатенации в рантайме — новые объекты. Сравнивать — `equals`.
- **Константа — только `final` с константным инициализатором.** `"hel" + "lo"` и `C + "lo"` при `final String C = "hel"` вычисляет компилятор; «эффективно final» не годится.
- **`String` неизменяема.** Любой «изменяющий» метод возвращает новую строку; `s.toUpperCase()` без присваивания ничего не делает, `+=` в цикле копирует всё накопленное.
- **`String` — последовательность UTF-16 `char`, а не символов.** `length()`, `charAt`, `trim()` работают с кодами `char`; Unicode понимают `codePoints()`, `strip()`, `isBlank()`.

## Пул строк и ==
- Одинаковые литералы — один объект, даже в разных классах и пакетах.
- `new String("hi") == "hi"` — `false`; `intern()` возвращает экземпляр из пула — тот же, что у литерала. Пул с JDK 7 в обычной куче и чистится GC.
- Типичный баг: `status == "PAID"` проходит тест (оба литерала) и не срабатывает на строке из БД.
- Null-безопасно: `"PAID".equals(status)`. Для статусов — лучше `enum`.

```java
String a = "hello";
final String c = "hel";
String e = "hel";
System.out.println(a == "hel" + "lo");          // true — константа
System.out.println(a == c + "lo");              // true — c константная переменная
System.out.println(a == e + "lo");              // false — рантайм
System.out.println(a == (e + "lo").intern());   // true
```

## Конкатенация
- С Java 9 (JEP 280) `javac` компилирует `+` не в `StringBuilder`, а в `invokedynamic` + `StringConcatFactory`: стратегию выбирает JDK при линковке.
- Но `s += x` в цикле всё равно создаёт новую строку на итерации — O(n²). В цикле — `StringBuilder` или `String.join`/`Collectors.joining`.
- `"" + null` = `"null"`: конкатенация `null` не падает.

## Методы String
- `trim()` убирает символы с кодом ≤ `U+0020`; `strip()` (Java 11) — всё, что `Character.isWhitespace`, включая `U+2003`.
- Неразрывные пробелы (`U+00A0`, `U+2007`, `U+202F`) `isWhitespace` не считает — `strip()` их оставит.
- `isBlank()` (11) — пусто или только пробелы; `isEmpty()` — только длина 0.
- `"a,b,,".split(",")` отбрасывает хвостовые пустые строки (длина 2); `split(",", -1)` — нет (длина 4).
- `StringBuilder.equals` не переопределён — сравнение ссылок. Содержимое — `s.contentEquals(sb)`.

## Unicode и регистр
- `"a😀".length()` = `3`: эмодзи вне BMP — суррогатная пара. Символов — `codePointCount` или `codePoints().count()` = `2`.
- `toUpperCase()` без аргумента берёт локаль по умолчанию: в турецкой `"title"` → `"TİTLE"`, и сравнение ключей ломается. Для идентификаторов — `toUpperCase(Locale.ROOT)`.
- Регистр может менять длину: `"ß".toUpperCase(Locale.ROOT)` = `"SS"`.
